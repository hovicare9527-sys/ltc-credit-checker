# 長照人員積分檢核

**[下載 Windows 免安裝空白版 v1.8.0（EXE）](https://raw.githubusercontent.com/hovicare9527-sys/ltc-credit-checker/5fcd9feedc0cfc2c2ca2bca3c08d94443a074bc1/downloads/LtcCreditChecker-v1.8.0-Windows.exe)**

下載後，在 Windows 電腦上按兩下 `LtcCreditChecker-v1.8.0-Windows.exe` 即可開啟。第一次使用時名單是空白的，各單位可匯入自己的 Excel，在本機核對居服員、督導及個管人員的繼續教育積分。

## 第一次使用

先用機構帳號登入衛福部長照人員系統，準備以下兩份 Excel（`.xlsx`），整份匯入即可。

| 準備的檔案 | 檔案內容 | 在本程式怎麼匯入 |
| --- | --- | --- |
| 機構人員教育訓練積分名冊 | 全體人員的上課日期、課程和積分 | 按「1. 積分名冊」，選取檔案 |
| 證明管理 | 每位人員的證照類別、生效日和到期日 | 按「2. 人員管理」→「匯入證明管理」，選取最新的檔案 |

匯入完成後，點左邊的人員姓名，右邊的**「這次還缺什麼」**會列出總積分還差幾點、缺哪些必修課，以及原住民族和多元族群文化課各差幾點。若出現「缺少可配對的證照」，請到「2. 人員管理」補上或核對該員的證照，再匯出報表。

## 匯出報表

| 我想要的資料 | 按哪裡 | 會得到什麼 |
| --- | --- | --- |
| 一個人的積分明細 | 點姓名 →「個人 PDF」 | 所選人員的積分與缺項 |
| 全單位還缺哪些積分 | 「匯出全員缺分 PDF」 | 全部職類合併成一份清單，自動存到「文件」→「長照積分報表」 |
| 每個人每月修了幾點 | 「匯出每月積分」 | 選月份算法和年度，把全員報表存成 Excel 或 PDF |

## 每月積分怎麼算？

例如某位同仁的證照在 **5 月 15 日**生效，**6 月 3 日**上完一堂 **2 點**的課。選不同算法，這 2 點會列在不同的區間。

| 月份算法 | 這 2 點列在哪裡？ |
| --- | --- |
| **依證照生效日** | 證照第 1 個月（5/15～6/14）。同一人有兩張證照時，每張證照分開列。 |
| **依日曆月** | 6 月（6/1～6/30）。同一人有多種職類時合併統計，同一堂課只算一次。 |

月報依**完課日**加總已匯入、已認可的實得點數，尚未扣除換證採計上限。月報中的 **0** 表示匯入資料在該區間沒有計入點數，**空白**表示資料待確認。
